# Noto Serif fonts

`noto_serif_regular.ttf`, `noto_serif_bold.ttf`, `noto_serif_italic.ttf`, and
`noto_serif.xml` (the `<font-family>` combining them) are copied from
Biblesprout (`apps/biblesprout_android/app/src/main/res/font/`).

Font: **Noto Serif**, published by Google as part of the Noto font family.
Exact version could not be determined from the Biblesprout checkout (no
embedded version metadata was checked and no accompanying license/version
file was found there to copy).

License: **SIL Open Font License, version 1.1** (the standard license for
the Noto font family). No `OFL.txt` was found anywhere in the Biblesprout
repository to copy verbatim — the canonical license text can be found at
https://openfontlicense.org or in the upstream Noto Fonts repository
(https://github.com/notofonts/noto-fonts).
